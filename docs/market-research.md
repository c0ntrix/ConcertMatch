# Market review

Research date: 27 September 2026.

Spotify Blend already combines friends' listening tastes. FestivalMates offers music compatibility and group festival planning. Movita combines local events, private groups and Spotify discovery. Who2See blends friends' preferences for festival lineups. ConcertMatch therefore enters an existing market.

The opportunity is a narrower task: help an existing group choose one reachable concert, with a fair score, understandable reasons and a shared shortlist. This is a product hypothesis, not proven demand.

Spotify API development access is limited to five allowlisted users. The published requirements for extended access are demanding, including an established organization and substantial active usage. A public launch should keep the independent history-file import and manual artist selection.

Ticketmaster supplies real events but does not cover all local venues. Its API quota requires caching. The biggest risks are import friction, incomplete listings and broad genre matching.

A sensible next step is testing with 10–20 real pairs or groups: can they finish setup, find a mutually appealing concert, and return for another outing? No growth or revenue claim has been validated.
